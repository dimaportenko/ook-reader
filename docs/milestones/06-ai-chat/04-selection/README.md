# Feature — Selection → prefilled chat

[← Milestone 6](../README.md)

The entry point AI Chat was built for: select a passage in the reader, press *Ask AI*, and
the chat drawer opens with a draft already in the compose box — book, author, chapter and
the quoted passage — so the only thing left to type is the question. Desktop first; the
native iOS edit-menu item is [Phase 21](../README.md#phases). The template itself already
exists (`ai::prompt::draft`, Phase 17 Step 2); this feature is the plumbing that feeds it.
