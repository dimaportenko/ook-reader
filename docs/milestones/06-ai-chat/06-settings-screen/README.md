# Feature — Settings screen

[← Milestone 6](../README.md)

A gear button in the library opens a full-screen settings view. On desktop it has a sidebar
of sections (*Reader theme*, *AI*); on a phone it is a list you tap into. The AI section has
one block per provider, only Gemini for now, and becomes the place where the OpenCode Zen
key and model list land in [Phase 23](../07-opencode/phase-23-opencode-zen.md).

| # | Phase | Status |
|---|---|---|
| 24 | [Settings screen](phase-24-settings-screen.md) | 🚧 in progress — opened 2026-09-27, ahead of Phase 23 |

**Why it comes first.** The reader's settings popover already holds eight controls. Phase 23
would add a second key row and a list of dozens of Zen models to choose from, and that
doesn't fit in a popover. A screen with room for it is the prerequisite.
